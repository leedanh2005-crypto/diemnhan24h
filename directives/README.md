# Directives

Thư mục chứa các SOP (Standard Operating Procedures) viết bằng Markdown.

Mỗi directive định nghĩa:
- **Mục tiêu** (Goal): Kết quả cần đạt
- **Inputs**: Dữ liệu đầu vào
- **Tools/Scripts**: Script nào trong `execution/` cần gọi
- **Outputs**: Deliverables
- **Edge cases**: Các trường hợp ngoại lệ và cách xử lý

## Quy tắc
- Viết bằng ngôn ngữ tự nhiên, như hướng dẫn cho nhân viên mid-level
- Directives là **tài liệu sống** — cập nhật khi học được điều mới
- Không tạo mới hoặc ghi đè directive mà không hỏi user trước
